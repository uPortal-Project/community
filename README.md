# uPortal Community

The working home for the uPortal project's cross-repo coordination and community
discussion.

Code-level work is tracked as issues **in the repo where the code lives**
(`uPortal`, `uPortal-start`, the portlets, the web components). This repo holds
the things that don't belong to any single repo:

- **Discussions** — announcements, design proposals / RFCs, Q&A, and ideas. This
  is our replacement for the wiki-style conversation we used to keep in Confluence.
- **Cross-repo tracking issues** — umbrella/epic issues for initiatives that span
  multiple repos (release waves, the portlet-removal campaign, the web-components
  migration). Individual tasks stay in their home repos and are linked from here.

## Where things live now

| Need | Home |
|------|------|
| Code-level bugs / tasks / features | Issues in the relevant code repo |
| Cross-repo epics & roadmap | This repo's issues + the **uPortal Roadmap** org Project |
| Announcements, RFCs, Q&A, ideas | **Discussions** in this repo |
| Reference documentation | https://uportal-project.github.io |
| Org profile & shared templates | the `.github` repo |
| Governance | `uPortal-steering-cmte` (steering committee, private) |

## Issue types

Issues across the org use three types — **Task**, **Bug**, and **Feature**.
Use them when filing.

## Background

The project moved its planning and knowledge base off Confluence and Jira to
GitHub. Non-sensitive coordination happens here in the open; anything sensitive
to a specific institution or employer stays out of GitHub.
